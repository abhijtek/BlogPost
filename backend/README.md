# project-camp-backend

A clean Node.js/Express backend implementing user registration, login, validation, and complete CRUD operations. Includes JWT-based authentication and structured API endpoints for user management.

## Assignment Documentation

- Postman collection: `docs/BlogPost.postman_collection.json`
- MongoDB schema documentation: `docs/mongodb-schema.md`

Import the Postman collection, set `baseUrl`, run the `Login` request, and the collection will save `accessToken` and `refreshToken` automatically for protected routes.
