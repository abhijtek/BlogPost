# MongoDB Schema Documentation

This backend uses MongoDB with Mongoose. The main collections are `users`, `articles`, and `articledailyviews`.

## User Collection

Model: `User`

Source: `src/models/user.models.js`

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Yes | Generated by MongoDB |
| `role` | String | No | Enum: `user`, `admin`; default: `user`; indexed |
| `avatar.url` | String | No | Defaults to `https://placehold.co/200x200` |
| `avatar.localPath` | String | No | Local avatar path if used |
| `username` | String | Yes | Unique, lowercase, trimmed, indexed |
| `email` | String | Yes | Unique, lowercase, trimmed |
| `fullName` | String | No | Trimmed |
| `password` | String | Yes | Hashed with bcrypt before save |
| `isEmailVerified` | Boolean | No | Default: `false` |
| `refreshToken` | String | No | Stored for refresh-token flow |
| `forgotPasswordToken` | String | No | Hashed temporary password reset token |
| `forgotPasswordExpiry` | Date | No | Reset token expiry |
| `emailVerificationToken` | String | No | Hashed email verification token |
| `emailVerificationExpiry` | Date | No | Verification token expiry |
| `review.reviewedBy` | ObjectId | No | References `User` |
| `review.reviewedAt` | Date | No | Review timestamp |
| `review.rejectionReason` | String | No | Trimmed rejection reason |
| `createdAt` | Date | Yes | Mongoose timestamp |
| `updatedAt` | Date | Yes | Mongoose timestamp |

### User Indexes

- `role`
- `username`
- unique index on `username`
- unique index on `email`

### User Methods

- `isPasswordCorrect(password)`
- `generateAccessToken()`
- `generateRefreshToken()`
- `generateTemporaryToken()`

## Article Collection

Model: `Article`

Source: `src/models/articles.models.js`

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Yes | Generated by MongoDB |
| `title` | String | Yes | Trimmed |
| `slug` | String | Yes | Unique, indexed |
| `content` | String | Yes | Blog/article body |
| `featuredImage` | String | Yes | Image URL/path |
| `status` | String | No | Enum: `draft`, `pending`, `published`, `rejected`; default: `draft`; indexed |
| `userId` | String | Yes | Author user id stored as string; references `User`; indexed |
| `tags` | String[] | No | Lowercase, default: `["general"]`, max 8 tags, indexed |
| `totalViews` | Number | No | Default: `0` |
| `publishedAt` | Date | No | Indexed |
| `review.reviewedBy` | ObjectId | No | References admin `User` |
| `review.reviewedAt` | Date | No | Review timestamp |
| `review.rejectionReason` | String | No | Trimmed rejection reason |
| `createdAt` | Date | Yes | Mongoose timestamp |
| `updatedAt` | Date | Yes | Mongoose timestamp |

### Article Indexes

- `slug`
- `status`
- `userId`
- `tags`
- `{ status: 1, publishedAt: -1 }`
- `{ status: 1, totalViews: -1 }`

## ArticleDailyView Collection

Model: `ArticleDailyView`

Source: `src/models/articleView.model.js`

This collection prevents unlimited repeated view-count increments by the same user on the same article.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Yes | Generated by MongoDB |
| `articleId` | ObjectId | Yes | References `Article`; indexed |
| `userId` | ObjectId | Yes | References `User`; indexed |
| `count` | Number | No | Default: `0` |
| `createdAt` | Date | Yes | Mongoose timestamp |
| `updatedAt` | Date | Yes | Mongoose timestamp |

### ArticleDailyView Indexes

- `articleId`
- `userId`
- unique compound index: `{ articleId: 1, userId: 1 }`

## Relationships

- One `User` can create many `Article` documents.
- One `Article` belongs to one author through `userId`.
- Admin users review submitted articles through `Article.review.reviewedBy`.
- `ArticleDailyView` links one user to one article for view tracking.
